# Fotos de los rubros del hero: origen y licencia

Fotografías de stock de **Unsplash** para la vista previa del hero (src/components/preview/). Son ejemplos de
diseño, no negocios ni clientes reales. Las de cafetería que empiezan por `cafeteria-` y no figuran abajo
(cappuccino, latte, café frío, cheesecake y torta) vienen de `kopa-caffe/assets-source/food`, también de Unsplash.

**Licencia:** [Unsplash License](https://unsplash.com/license): uso libre, también comercial, sin pedir permiso ni
atribuir (la atribución es opcional). No se pueden revender tal cual ni usar para montar un servicio de fotos competidor.

Para cambiar una foto: guarda un JPG con la misma clave en esta carpeta y ejecuta `npm run assets`.
